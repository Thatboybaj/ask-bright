# Custom Framer code components

Bright writes custom React code components for Framer when the built-in tools are not enough.

## Examples
- ScrollSticker: a scroll-linked sticker animation built with framer-motion.
- Multi-file upload components with full property controls (addPropertyControls) so designers can configure them without code.
- A theme switcher / dark mode override component.

## Skills shown
React, framer-motion, Framer property controls, building components that non-developers can use.
