# About Bright Ajiboye

Bright Ajiboye is a freelance web designer and developer based in Qatar, originally from Nigeria. He specializes in Framer and Webflow and works with international clients through agencies and direct outreach.

Alongside client work, he designs and sells Framer templates and builds custom Framer code components in React.

- Awwwards Academy course certificates
- Currently taking FORMBURG's Webflow Expert Course

## Services

- Custom Framer code components (React, framer-motion)
- CMS architecture for content-heavy sites
- Framer templates for editorial niches
