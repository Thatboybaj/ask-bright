# Website Audit Agent

AI Website Audit Tool

Personal product

AI engineering & design

An agent that audits any website across 10 core areas, scores it out of 100 and returns a prioritised action plan, quick wins, an executive summary and a ready-to-send outreach email.

## Overview

Paste a URL and the agent crawls the site, runs checks across 10 areas, scores it and writes the report. It is built for freelancers and agencies who want to open a conversation with a prospect using real findings.

## How it works

Crawler: pages, robots.txt, sitemap, broken links, SSL, redirects, exposed files and assets.

PageSpeed Insights for lab and real-user Core Web Vitals on mobile and desktop.

A headless browser renders the site at phone and desktop sizes to check tap targets, contrast, overflow, CTAs and popups.

Claude reviews copy for relevance and clarity.

Each source is optional. Checks that can’t run are marked as skipped instead of guessed.

## The 10 areas

Technical SEO

Performance

Mobile usability

On-page SEO

User experience

Conversion

Content quality

Security

Accessibility

Analytics and tracking

## Scoring

Each check passes, warns or fails, weighted by impact. The weighted results roll up into a health score from 0 to 100 with a clear band from Excellent to Critical.

## Report and app

The report follows a cheat-sheet layout with the score, an executive summary, how visitors see the site, all 10 areas and a prioritised action plan. It exports to PDF. The web app on Vercel keeps an audit history and has a daily limit for demo visitors.

Outcome

A Python agent with a web app, an HTML and PDF report, and Markdown and JSON outputs for automations. Every finding comes with a fix, its impact and the effort it takes.
