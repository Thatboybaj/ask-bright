# C.Black

Landing Pages

Christina Black

A scalable Framer landing page system for a luxury brand consultancy, built to sit seamlessly alongside its Squarespace site.

© C.Black

## Overview

c.black is the personal brand and consulting practice of Cristina Black, helping premium beauty, fashion, and luxury brands define how they speak, position themselves, and grow.

The goal was to create a series of high-converting landing pages that would integrate seamlessly with the existing website while establishing a stronger conversion path for enterprise-level clients. Beyond designing individual pages, the project evolved into building a scalable landing page system that supports future growth without sacrificing consistency or quality.

## The Challenge

c.black already had an established Squarespace website, but it lacked dedicated, conversion-focused experiences for its growing suite of services.

The challenge wasn't simply to design new landing pages—it was to create a conversion layer in Framer that integrated seamlessly with the existing Squarespace website. Visitors needed to move between both platforms without ever feeling like they were switching websites. This meant:

Designing 6–7 high-converting landing pages that matched the existing brand experience.

Creating a cohesive visual language across both Squarespace and Framer.

Building clear user journeys that guide enterprise prospects toward inquiries.

Maintaining the editorial aesthetic while improving conversion.

Ensuring a responsive, high-performance experience across every device.

## My Role

I led both the design and Framer development of the conversion experience. Responsibilities included:

Designing conversion-focused landing pages.

Developing the pages in Framer.

Creating a reusable component system for future expansion.

Matching typography, spacing, navigation, and interactions to the existing Squarespace experience.

Ensuring users could transition between Squarespace and Framer without any visual or UX disconnect.

Optimizing responsiveness and performance across desktop, tablet, and mobile.

## Solution

Rather than creating a standalone set of landing pages, I designed a unified website system.

Every design decision from typography and spacing to navigation patterns, component styling, and interactions was carefully aligned with the existing Squarespace website so the entire experience felt like one cohesive product.

Behind the scenes, I also built a modular component system in Framer, allowing new service pages to be created quickly while maintaining consistency across the growing site.

## Outcome

The project delivered far more than a collection of landing pages. It established a seamless bridge between Squarespace and Framer, giving visitors the impression of navigating a single, cohesive website while introducing a significantly stronger conversion layer for enterprise clients. The result includes:

9 premium landing pages.

A unified design language across Squarespace and Framer.

Consistent navigation and user experience throughout the site.

A reusable component library for rapid future expansion.

Responsive, high-performance pages optimized for conversion.

A scalable foundation that supports continued growth without compromising the brand experience.

The finished website delivers an entire website ecosystem built around clarity, conversion, and long-term scalability.
