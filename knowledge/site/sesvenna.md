# Sesvenna

Architecture Studio

Framer Marketplace

An editorial Framer template for architecture practices, built like a set of drawing sheets, with data-driven projects and four custom code components.

© Sesvenna

## Overview

Sesvenna is a premium Framer template for architecture, landscape and interior practices, available on the Framer Marketplace . It started with a brief I set myself: design a site for a studio that only builds where the weather decides. Alpine sites, short build windows and snow loads that shape every decision.

That brief led to the core idea. The whole site reads like a set of drawing sheets. Every section is numbered, ruled and labelled like a title block, so the work looks precise before anyone opens a project.

## My Role

Concept, brief and art direction.

CMS architecture for Work, Journal, Team and Careers.

Four custom React code components.

Framer build, responsive across desktop, tablet and phone.

SEO setup, preview site and marketplace launch.

## The Challenge

Architects think in drawings and data: altitude, area, orientation, build phases. Their websites usually hide all of that behind a photo grid. The challenge was to bring that data forward and make it useful, while keeping the site calm and editorial.

It also had to stay easy to run. A small practice should be able to add a project, swap images and publish without breaking the drawing-sheet system.

## Design Approach

Projects carry data, and the template uses it. The work index sorts by altitude. Each project opens with a datum line and a facts sheet, then moves through the brief, site conditions, a build log, drawings, gallery and credits.

Typography does most of the work. Archivo carries the editorial voice, and Geist Mono handles labels, coordinates and numbers, the way annotations sit on a technical drawing.

## Custom Code Components

Datum Crosshair: a hero image with a live altitude scale and a crosshair that follows the cursor. Image, range and datum are editable, and touch scrolling is never blocked.

Project Drawings: a switcher for plan, section and elevation drawings.

Index Controls: filter and sort the work index.

Live Clock: local time for each studio location.

## CMS Architecture

Work: 30+ fields, including altitude, area, status, site stats, drawings, gallery and credits.

Journal: essays, site diaries and news.

Team and Careers: partners, staff and expandable open roles.
