# SCV

Redesign Concept

'26

Johannes Röhrenbach

Art direction, Web design

A cohesive overview system for the Swiss Choral Association's network of independent member associations.

View on Contra

© SCV

## Project Context

The Swiss Choral Association (SCV) manages a large network of regional choir associations across Switzerland. Each member association operates independently, with its own branding, website, and communication style. SCV’s current website structure does not reflect this clearly, and many associations are not open to redesigning or adjusting their own websites.

SCV needed a way to present its network professionally while respecting the visual identity and autonomy of each member association.

## Objective

To redesign the SCV subpages so they:

Provide a clear, modern overview of each member association

Maintain design consistency within SCV’s site

Avoid redesigning any external association websites

Link directly to the association’s own website

Create a scalable system that works as SCV grows

## Strategic Approach

Instead of trying to represent each member association as a full subpage, I proposed a lightweight directory-style format. Each association gets a clean, modern “preview section” that includes:

## 1. Overview Block

Name of the association

Short description (mission, region, or focus)

Key information in a simple layout

## 2. Visual Preview

A representative image or small visual card

Consistent styling that fits SCV’s brand

Cinematic, warm, Swiss-inspired photography where required

## 3. External Link

Prominent CTA leading to the association’s real website

Ensures users can quickly access the official content

No attempt to modify or mimic the association’s own design

This respects the independence of the associations while making the SCV site clearer and more usable.

## Design Direction

The visual tone is cinematic, authentic, and warm, reflecting the emotional and human side of choir culture. Image art direction includes:

Close-up choir portraits

Black & red choir robes for consistency

Soft lighting

Swiss interiors and natural textures

Realistic, editorial-feel photography

This creates a cohesive identity across SCV’s pages without interfering with member branding.

## Deliverables

Full page structure and UX for the Association Overview

Modular components built in Framer

Preview card layouts

CTA linking system

Visual direction for choir imagery

Scalable template for future association additions

## Outcome

A clearer hierarchy between SCV and its member associations

A unified SCV visual identity without altering member sites

A more intuitive user experience

A scalable framework that works long-term

Respect for each association’s independence and existing design

The new structure transforms SCV’s association pages into a clean, modern overview hub, making it easier for visitors to understand the network and navigate to official association websites — all while keeping SCV’s branding cohesive and professional.

A clear overview hub with a unified SCV identity and a scalable template, respecting each association's independence while making the network easier to navigate.
